# 缺陷模板保留契约差异、复现与环境

创建于 2026-09-08。

## 结论与边界

缺陷模板描述已约定行为的失效及修复目标，目标文件为 `.github/ISSUE_TEMPLATE/bug.yml`，前缀为 `[缺陷]`。相对 [共通规范](../README.md#d-20260908-issue-template-common)，保留旧表单已有的实际/期望、复现、环境职责，并统一问题字段 ID。根因未知或暂未复现仍可跟进缺陷；期望本身未确认时先澄清，不把新需求写成既有保证。选类归 [分类决定](../README.md#d-20260908-issue-classification)。

### 相对共同基线的增删改

| 操作 | 字段 | 内容与取舍 |
| --- | --- | --- |
| 改写 | `problem`：实际与期望行为 | textarea，创建必填。写触发条件、观察结果、期望及现行依据、影响；区分事实与根因猜测 |
| 增加 | `reproduction`：复现步骤与已有证据 | textarea，创建必填。给可执行步骤、最小输入、实际频次和已有尝试；无法复现时如实写缺少条件，不预填根因 |
| 增加 | `environment`：版本与相关运行条件 | textarea，创建必填。只收与问题相关的提交/版本与配置，未知或不适用写清理由，不要求所有开发工具清单 |
| 删除 | 无 | 未复现不删除修复验收；缺陷同样需要交付、依赖与后续归属 |
| 保留并解释 | `acceptance` 等其余七字段 | 共通结构保持一致；验收核对恢复契约与相关回归，补证进展和修复事实分别记录 |

完整表单共十个输入块；problem 后依次放 reproduction、environment。运行问题按需分开记录 Harness 及版本、镜像与依赖、节点 skill/MCP 等能力配置，以及外围 Run/NodeTask/Attempt 身份、时间和输入输出；不把“Docker 环境”作为全部条件，也不强制收集容器内 agent 会话或工具轨迹。证据按可共享范围提供脱敏内容。

### 旧字段迁移

现有 bug.yml 用 `behavior` 表达实际/期望。新表单将该 ID 映射为共同 `problem`，仍保留“实际与期望行为”的用户可见含义；其余既有字段 ID 保留，增加共同 deliverables 和 handoff。不能同时留下 behavior 与 problem 两个重复问题块。

迁移只针对后续模板定义；已提交 Issue 的正文、确认和证据不批量改写。若后来有读取旧 ID 的工具，按 behavior→problem 显式兼容并验证，而不假定工具已自动迁移。当前正式仓库未发现这种消费自动化；模板部署时仍需核对实际依赖。

## 方案考量（alternatives）

| 方案 | 可取之处 | 代价或不适用原因 | 本次取舍 |
| --- | --- | --- | --- |
| 只用共通问题与验收 | 表单短 | 缺少触发、相关环境和调查证据，后续需反复追问 | 保留复现与环境专用块 |
| 已复现、已知根因才允许建 Bug | 输入看似可直接执行 | 丢失间歇故障与外部报告，容易编造原因 | 允许未知，按预检处理证据缺口 |
| 保留 legacy behavior，作为共通字段例外 | 少改旧 ID | 语义相同却需为共同核对长期维护别名 | 新表单统一 problem，显式记录迁移 |
| 增加 problem 并同时保留 behavior | 旧字段仍在 | 重复描述同一问题，可能出现两种期望 | 只保留一个问题块 |
| 强制全量环境与内部 agent 日志 | 调查资料可能更充分 | 无关信息负担大，超出外围记录边界 | 按问题收相关环境与外围证据 |

## 影响与验证

用“已复现的历史时点输出错误”和“尚未复现的节点 I/O 串用”两种填写例核对字段。前者应能写触发及修复验证，后者应能如实保存未知、补证责任和修复目标；例子是假设，不构成真实产品故障报告。

实施时核对 behavior→problem 映射、旧字段无丢失、十字段与共通基线一致；后续实际修复须对原失败条件和相关回归留证据。无法复现由主责按 [原预检流程](../README.md#d-20260907-development-workflow) 决定补证或处置，不能把“研究完成”冒充修复。当前文本核对见 [设计验证记录](../../../../docs/validation/2026-09-08-issue-template-decisions.md)，未运行故障复现。

## 重开条件

真实故障反复缺同一种关键条件、旧 ID 消费工具出现兼容需求，或非运行类缺陷被强迫填写大量无关环境时，修订专用提示或例外，不静默删除证据职责。
