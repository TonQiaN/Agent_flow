# 研究模板用证据问题与停止条件限定交付

创建于 2026-09-08。

## 结论与边界

研究模板用于可独立验收的未知事实调查，目标文件为 `.github/ISSUE_TEMPLATE/research.yml`，前缀为 `[研究]`。它在 [共通规范](../README.md#d-20260908-issue-template-common) 上补充方法和结束边界，不强迫输出产品代码或“可行”结论。若最终承诺是完整功能或工程文件，内部研究阶段不改变主类，按 [分类决定](../README.md#d-20260908-issue-classification) 判断是否值得独立拆项。

### 相对共同基线的增删改

| 操作 | 字段 | 内容与取舍 |
| --- | --- | --- |
| 改写 | `problem`：研究问题与决策用途 | textarea，创建必填。说明要回答的未知、已有事实及证据将影响的具体功能、方案或开发安排 |
| 增加 | `evidence_plan`：方法、比较与证据计划 | textarea，创建必填。列真实候选/假设、资料或实验方法、比较基线、适用版本/样本和可能推翻判断的结果；不要求资料研究虚构实验 |
| 增加 | `stop_rule`：结束条件与投入边界 | textarea，创建必填。限定问题、时间/资源或样本等适用边界，说明支持、不支持、仍不确定时怎样交付、补证或交接 |
| 删除 | 无 | 没有代码不代表没有范围、交付和验收；相关决定与续接仍按阶段补充 |
| 保留并解释 | `acceptance` 等其余七字段 | 验收回答是否按约定方法获得可检查结论及适用限制，不要求研究者一定证明原设想成功 |

完整表单共十个输入块；problem 后依次放 evidence_plan、stop_rule。计划描述准备怎样取证，执行结果和证据位置进入验收/续接与实际产物，不能把计划句写成已执行。

### 结论与结束边界

研究结论可以支持、不支持或有界地仍不确定。否定结论在约定研究问题得到充分回答时可以完成验收；若必要环境、样本或证据没有取得，则记录阻塞、补证与去向，不能仅因预算耗尽就勾选完成。只有原验收明确接受某种有界不确定结论，且已履行约定方法和限制说明时，才可按该结果验收；改变研究目标需明确修订范围。

产物可以是正式决定本身，只要正文足以说明比较、证据、局限和取舍；需要较多实验记录时另列研究/验证交付物。研究采纳某方案不表示后续实现已完成；列清实施去向、剩余未知和重开条件，不要求为讨论先建立所有后续 Issue。

例如验证指定 DSH 版本是否能在同镜像下隔离两个节点的插件能力：固定环境与节点配置，观察允许和禁止行为的外围输入输出，区分依赖缺失、接口不支持和隔离失效。只验证计划内版本/配置，不推广成所有 Harness 都支持；镜像环境与节点能力分层是既有用户边界，实验不以采集 agent 内部轨迹为前提。此例是方法说明，未执行实验。

## 方案考量（alternatives）

| 方案 | 可取之处 | 代价或不适用原因 | 本次取舍 |
| --- | --- | --- | --- |
| 沿用功能模板，验收“能力可用” | 容易接实现 | 把未知答案预定为成功，不能诚实交付否定结论 | 研究按证据问题验收 |
| 只写“调研某能力”与报告路径 | 建项快 | 范围无限，难判断证据是否充分、何时结束 | 增加方法与停止条件 |
| 所有研究固定时间、样本数和实验类型 | 形式可比较 | 文献核对、接口探索和性能实验所需边界不同 | 具体工作自行声明适用投入与方法 |
| 方法与结束条件独立成块 | 便于识别证据不足和控制扩展 | 与验收相关，需要区分执行边界和成果标准 | 采用，支持有依据的否定结论 |

## 影响与验证

新增研究表单与使用说明，验证十字段及共通一致性。填写演练至少覆盖 Container 能力核对、结论为不采用、必要条件缺失三种情形；检查是否能明确“没测、仍未知、结果否定”而不混为一谈。仅决策交付时检查正文能自足承载结论；不要求运行产品测试来验模板。

本轮文本核对见 [设计验证记录](../../../../docs/validation/2026-09-08-issue-template-decisions.md)，未进行上述实验或长期填表负担测量。

## 重开条件

真实研究经常无限延长、停止条件与验收冲突、否定结论被误当未完成，或方法字段对某类有价值的研究明显不适用时，以实际工作项修订。不能为每次方案选择强制先建研究 Issue。
