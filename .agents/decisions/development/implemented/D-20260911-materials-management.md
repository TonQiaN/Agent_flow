# materials 保留本地原始资料，选定内容通过飞书共享

创建于 2026-09-11。

## 结论与边界

materials 是自由组织的本地原始资料区。原始内容默认不进入 Git，只有目录根级的 `AGENTS.md`、`CLAUDE.md`、`README.md`、`.gitignore`、`.ignore` 五份管理文件入库；子目录中的同名文件仍属于原始内容。已有被跟踪的原始文件退出索引时保留本地原件，本次不清理 Git 历史。

值得团队成员复用或讨论的选定资料，例如某个 artifact，通过飞书 CLI 管理。Git 保存项目规则和正式知识，飞书承接选定资料的团队访问，本地 materials 保存自由整理的原始内容；不要求每份本地资料上传，也不因上传就将内容采纳为项目规则。正式决定仍须自足，不依赖原始文件或飞书链接才能理解和执行。

团队共享使用 AgentFlow 飞书组织，CLI 操作显式指定 `--profile AgentFlow`，并核对实际应用和操作身份。该配置与组织的对应关系已通过本机在线认证及飞书开发者后台核实；组织名称不解释为新建同名文件夹或知识库的要求。本轮未指定待上传资料或团队访问对象，实际上传、目录建设与权限调整不在本次交付范围。

原始格式、命名、目录和索引继续不作统一要求，沿用 [既有拒绝边界](../README.md#d-20260907-mandatory-source-traceability)。默认检索可发现管理文件，原始内容仅在任务需要时限定范围读取。这里只划定保存、检索和协作边界，不重新制定原始材料包规范。

### 局部指令的唯一书写归属

| 受管文件 | 作用范围 | 书写职责 |
| --- | --- | --- |
| [materials/AGENTS.md](../../../../materials/AGENTS.md) | materials 及其子目录 | 原始资料与正式知识的边界、Git 和检索范围、选定资料的团队共享入口 |

本决定是该文件唯一负责决定；同目录 `CLAUDE.md -> AGENTS.md` 使用相对符号链接共用正文。局部指令保持简短、准确、具体，操作说明链接到 docs，README 只作入口说明和导航，取舍保留在本决定。根 AGENTS.md 只增加必要的团队提示和按任务读取入口，书写仍由 [根入口决定](../README.md#d-20260910-root-agents-writing) 独立负责。

## 方案考量（alternatives）

| 方案 | 可取之处 | 代价或不适用原因 | 本次取舍 |
| --- | --- | --- | --- |
| 原始资料继续随 Git 分发 | 克隆即可取得被跟踪资料，沿用现状 | 自由增长的原文和大附件进入代码历史，无法按团队需要选择共享范围 | 用户明确改为原始内容默认忽略，仅管理文件入库 |
| 忽略整个 materials，包括管理文件 | 忽略方式简单 | 新 checkout 丢失目录说明与跨工具指令入口 | 保留五份根级管理文件，原始子目录不例外放行 |
| 本地保存原件，选定资料通过飞书 CLI 共享 | 兼顾自由整理和团队访问，符合用户已有工具选择 | 上传对象、身份、访问范围仍需按实际任务核对；Git 不再提供原始资料分发 | 采用，不要求整体搬迁或统一原始格式 |

## 影响与验证

新增局部指令、符号链接和 Git 忽略规则，同步默认检索、根入口及当前说明。已有 checkout 在接收取消跟踪的提交前需另存原件，更新后按需恢复；仅新增忽略规则不会使已跟踪文件退出 Git，也不会替协作者备份。

核对五份管理文件可入库、原始内容及任意深度同名文件被忽略、已有原件保留且摘要一致、指令唯一归属和全部同目录符号链接有效。飞书验证区分 profile、应用、实际组织和资料访问权限，未取得的证据如实记录，不以登录成功代替共享验收。

当前说明见 [资料管理指南](../../../../docs/development/materials.md)，目录管理、原件保留及 CLI 组织核对见 [验证记录](../../../../docs/validation/2026-09-11-materials-management.md)。管理文件和约定已在工作分支落实并验证；implemented 仅覆盖本次文件与连接归属核对，不代表已合入 main、完成真实资料共享或验证所有团队成员的访问权限。

## 重开条件

出现必须随代码交付的测试素材时，先判断其是否应进入正式源码或测试目录；确需改变原始资料的 Git、归档或共享边界，团队协作工具或目标组织发生变化，或现有指令产生重复误解时，再修订本决定。不因局部资料混乱重开统一原始规范的旧否决方案。
