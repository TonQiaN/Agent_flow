# 本机工作流展示与启动服务

创建于 2026-09-15。

## 结论与边界

#39 首版部署于团队成员自己的电脑。采用 TypeScript 本机 HTTP 服务和 React 前端；服务仅绑定 loopback，技术设置来自本机配置，页面只读。上传与启动使用同源校验、大小和文件类型限制、一次性输入校验及幂等提交标识。服务不向浏览器发送凭据。每次运行独立数据目录和执行子进程，共享同一个展示入口；保存最新元数据、引擎检查点/观察记录、不可变文件、事件和终止原因。

应用层以已登记的 examples 入口启动真实工作流；通过固定子进程入口跨越应用与示例边界，不开放客户端选择程序或任意宿主路径。现有完整工作流分别登记环境要求和材料表。原有 CLI 入口也使用共同记录目录，页面可以发现。Tutor 外部依赖缺失时明确显示条件，不替换为虚构流程。

结构与绑定均从实际已编译定义提取，历史只读取已保存记录。内部 Run/Attempt/并行子任务关联原样保留，序号和宿主时间驱动回放，回放没有执行副作用。原始文件复制到本次目录并校验摘要，浏览器只按注册文件 ID 取文件，禁止任意路径读取；新上传未启动前仍留在同一个弹窗。

前端框架和画布采用 React、Vite、React Flow，依赖精确锁定。其拖动、缩放、节点/连线选择适合本次展示交互；执行图不可在页面编辑。页面交互与浏览器验收在本决定下述章节定义。

## 画布与查看交互

第三层实现固定左侧导航、工作流目录、历史列表和设置页面；运行详情共用同一张 React Flow 画布。节点可拖动、画布可缩放，位置只影响本机浏览偏好。连线详情包含源/目标、outcome、返工上限和数据契约；节点详情按真实执行身份选择次数，分别显示输入、输出、容器设置与日志。运行、文件和历史错误使用明确的中文状态。

回放使用记录序号和真实时间，按选定时刻读取父、子运行的已保存修订；暂停/播放/逐条跳转仅切换视图，不能调用运行入口。按修订号或时刻直接查询所需快照，避免每一帧反复解析整段历史；相同时间按保存顺序选最后一条。回放中切换子运行继续使用相同时刻。最终招聘结论只在业务交付关卡通过后按二元结果展示；节点契约通过和整个工作流通过分别标注。文件 HTML 只读文本预览；PDF 由本地 PDF.js worker 渲染到 canvas 并提供分页和可访问文字，图片走同源预览。旧修订缺少时间时，只显示该修订本身；不能跨运行对齐的子运行、文件和事件明确标为不可回放，避免混入之后产生的信息。没有执行身份的节点不显示其他节点日志。

上传弹窗一次收集岗位、候选人、归属和全部文件；技术配置只读，上传按钮和拖放共用校验。同一逻辑提交跨 multipart boundary 保持幂等。窄屏切为单栏并保留画布、详情和导航。端到端 CI 从真实服务提交合成招聘到报告、历史、回放；Astra 在实际浏览器完成点击、拖动、截图识别，修正问题后重走路径，报告和截图仅保存在本机 materials/issue39-user-report。

执行日志归档属于本次运行的必需记录。归档回调失败时，节点返回明确的记录失败，不继续到后续节点，也不重复调用同一回调。已捕获的输出在调用归档前登记清理归属，失败后仍可按原执行身份释放临时文件；不能因展示记录失败丢失资源所有权。
