# 本机工作流展示与启动服务

创建于 2026-09-15。

## 结论与边界

#39 首版部署于团队成员自己的电脑。采用 TypeScript 本机 HTTP 服务和 React 前端；服务仅绑定 loopback，技术设置来自本机配置，页面只读。上传与启动使用同源校验、大小和文件类型限制、一次性输入校验及幂等提交标识。服务不向浏览器发送凭据。每次运行独立数据目录和执行子进程，共享同一个展示入口；保存最新元数据、引擎检查点/观察记录、不可变文件、事件和终止原因。

应用层以已登记的 examples 入口启动真实工作流；通过固定子进程入口跨越应用与示例边界，不开放客户端选择程序或任意宿主路径。现有完整工作流分别登记环境要求和材料表。原有 CLI 入口也使用共同记录目录，页面可以发现。Tutor 外部依赖缺失时明确显示条件，不替换为虚构流程。

结构与绑定均从实际已编译定义提取，历史只读取已保存记录。内部 Run/Attempt/并行子任务关联原样保留，序号和宿主时间驱动回放，回放没有执行副作用。原始文件复制到本次目录并校验摘要，浏览器只按注册文件 ID 取文件，禁止任意路径读取；新上传未启动前仍留在同一个弹窗。

前端框架和画布采用 React、Vite、React Flow，依赖精确锁定。其拖动、缩放、节点/连线选择适合本次展示交互；执行图不可在页面编辑。具体页面交互及浏览器验收将在后续同一决定中补充。
