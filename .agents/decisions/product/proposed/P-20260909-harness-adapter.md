# Harness Adapter 只生成调用并解释执行证据

创建于 2026-09-09。

## 结论与边界

按 #10 已确认设计，统一 HarnessTask、调用计划、事件和最终执行事实；每个 Harness 单独实现并显式注册。Adapter 不读取秘密、文件系统或启动进程，不决定 Workflow 路由和业务产物是否有效。用户 prompt 原样传递，固定目录与宿主执行配置不由任务内容改写。

首个组合选 Codex 订阅与 Docker，针对实际容器版本 0.153.4 验证；本机 CLI 及旧声明为 0.146.1，不把两者等同。模型由调用配置明确给出并校验名称格式，远端账号/模型可用性以实际调用为准。初始只接受明确映射的推理档位、禁用子 Agent 和禁用搜索配置；预算、任意 argv/env、未知字段及未支持功能启动前拒绝，不静默降级。后续真实证据允许扩展同一 Adapter，不新建全 Harness 分支的公共执行器。

Codex 调用采用 exec --json、严格配置、独立 CODEX_HOME、忽略用户配置/规则、固定 cwd 和非交互权限。身份、业务输入输出目录继承引擎；安全权限配置拒绝模型工具读取或移动认证文件，并允许修改 input/work/outputs。外层容器和内层文件约束必须联合实测，未验证时不声称秘密隔离已完成。

stdout JSONL 的 turn.completed 是 Harness 终态证据；还须 Runner 实际退出 0、停止确认及完整采集才可返回正常结束。合法 JSON、聊天“完成”、单个消息或非空目录都不能替代终态。缺失终态、畸形事件、未知编码、截断、冲突终态及 Harness 错误为执行失败。相同终态重复只接纳一次；usage 只取明确终态字段，不遍历嵌套同名字段、不累计重复快照，缺失为 unknown。

普通事件由传入的脱敏接口处理消息/工具文本；认证层提供秘密过滤，Adapter 不取得秘密存储权限。保留事件类型、item ID、来源及 Attempt 关联；未知事件记录类型与诊断，不把未知载荷整段复制进普通日志。raw 原件保持私有。首个 parser 使用结束后完整流解析，不宣称实时推送或完整原生轨迹。

单正常出口不要求模型写完成文件；结构化多出口通过 output-schema 约束最后响应的 outcome，实际输出仍放 outputs 并由独立 contract 验证。schema 通过只读配置注入，不能成为业务 artifacts 清单。本切片先实现独立接口、计划与 parser；真实 Runner/认证/网络、文件交付校验及可信前序证据须继续在 PR3/后续 Workflow 切片接通。

## 方案考量（alternatives）

| 方案 | 收益 | 代价 | 取舍 |
| --- | --- | --- | --- |
| 三个独立 Adapter + 显式注册 | 差异局限于调用/解析，可用替身测试 | 需逐个维护支持矩阵 | 用户确认采用 |
| 通用命令/环境透传 | 配置灵活 | 无法前置检查承诺和认证边界 | 不采用 |
| 从聊天尾句推断完成 | 不需要机器协议 | 无法区分失败、截断与真正终态 | 不采用 |
| 默认 usage=0 或递归累加 | 表格容易填满 | 将未知写成零或重复计数 | 明确 unknown 与唯一终态字段 |

## 影响与验证

对应 #10 及 #9/#11/#12 联合边界。先验证注册、参数拒绝、原样 prompt、身份关联、畸形/截断/未知事件、终态冲突与 usage；随后用选定真实版本验证调用、文件权限、认证/网络和正常交付。仅 parser/替身测试不能关闭 #10，也不能称整个首个真实组合已完成。

2026-09-09 的真实离线探测要求 filesystem 使用 TOML inline table 与 deny 枚举，已修正映射。严格配置通过后仍遇 bwrap namespace 初始化失败，须在执行集成层兑现内部沙箱需求；不通过关闭沙箱规避。当前接口/parser 与存储共 46 组检查通过（含 Docker），真实模型调用未完成，详见 docs 对应验证记录。

## 重开条件

实际版本更改事件/参数或必需采集方式时重新验证并更新本决定及矩阵；不默默接受未知版本或从日志猜测字段。支持搜索/子 Agent/预算必须提供实际证据。
