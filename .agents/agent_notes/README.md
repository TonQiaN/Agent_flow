# agent_notes

这里收录产品与开发流程的正式笔记，保存浓缩的选择、理由、边界和确认依据，正文按生命周期目录组织。既有决策记录继续使用原稳定 ID；目录名称不改变其效力，也不把未经确认的会话内容变成项目规则。

| 入口 | 内容 |
| --- | --- |
| [AGENTS.md](AGENTS.md) | agent_notes 的操作规则 |
| [产品索引](product/README.md) | 用户、功能、架构、Harness、页面与交互 |
| [开发流程索引](development/README.md) | 决策、文档、开发与评审方法 |
| [共同模板](TEMPLATE.md) | 正式笔记的起草结构 |
| [维护指南](../../docs/development/documentation.md) | 当前文档操作说明 |

两个分类中均有 proposed、implemented、archived、rejected 目录。proposed 收录尚未全部落实的决定，讨论、分工及审查确认由对应 Issue 承接。各记录通过分类索引中的稳定 ID 定位；当前产品方向仍为提炼候选。

团队的 CI 与 AI 审查组合见 [两人团队的 CI 与 AI 审查分工](development/README.md#d-20260918-ci-ai-review)。
