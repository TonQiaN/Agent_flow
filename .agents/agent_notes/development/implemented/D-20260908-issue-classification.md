# 用所属领域与五类交付目标区分主 Issue

创建于 2026-09-08。

## 结论与边界

主 Issue 分别说明所属领域与主要交付目标。领域回答讨论面向哪里，主类型回答最后承诺交付什么；两者独立，不以文件载体或是否已有产品代码判断工作是否成立。

| 所属领域 | 含义 |
| --- | --- |
| 开发流程 | 团队开发、协作、文档治理、Issue / PR、开发指令等工作方式 |
| 项目内容 | AgentFlow 的产品范围、功能、行为、架构及相关产品研究 |

五类主 Issue 都提供领域单选，由填写者确认所属领域。YAML 不指定 default，但 2026-09-10 的 GitHub 实际界面仍预选第一项“开发流程”；这不是自动分类结果，填写者应核对并按需切换。混合事项按主要目标选择，在范围中说明交叉影响；不增加“混合”兜底类别，也不引入自动分类。

| 类型 | 主要问题与完成条件 |
| --- | --- |
| 功能 | 新增或改变什么产品能力；完成约定行为及可核对的结果 |
| 缺陷 | 什么已约定行为失效；恢复该行为，未知根因或未复现不妨碍如实建项 |
| 研究 | 哪个未知问题需要回答；交付有依据的结论、适用限制和未解决部分，答案可以否定原设想 |
| 决策 | 团队需要作出什么选择；交付自足的正式决定、确认范围及后续归属，采纳不表示产品已实现 |
| 维护 | 要落实什么工程、文档或协作改进；交付约定文件或工程结果，名称不豁免非平凡改动的流程 |

主类型不表示工作阶段。包含研究、讨论和模板实施的 #21，主要交付仍是维护结果。不为每次 AI 会话、内部步骤、工作分支或 PR 自动新建 Issue。需要独立负责和交付的工作可以关联 Sub-issue；父子关系说明工作归属，任务依赖说明何者阻塞何者，PR 关联说明实际交付，均不增加第六种主类型。

分类和五表要求适用于主 Issue。Sub-issue 的内容、形式与是否使用这些分类由对应负责人自主决定，不把主表的领域、前缀或字段变成子项写作要求；其表达边界归 [共通决定](../README.md#d-20260908-issue-template-common)。主 Issue 描述整体需求，Sub-issue 让对应负责人自主组织其承担的具体工作，两者均以自然语言说明职责。

### 入口与完成事实

五个入口名称标明“主 Issue”，标题仍使用 `[功能]`、`[缺陷]`、`[研究]`、`[决策]`、`[维护]`。不另建必选类别标签、组织级 Issue Types 或固定 Assignees。模块、优先级、版本和关闭原因另按实际需要表达。

改变产品 Prompt 以新增行为可归功能，恢复既有输出要求可归缺陷，改善团队开发指令可归维护。开放聊天、一般问答或同项交接优先留在已有沟通中。取消、重复、延期、无法复现须表达真实处置，不当作实现或修复；完整验收与关闭归 [开发流程决定](../README.md#d-20260907-development-workflow)。

## 方案考量（alternatives）

| 方案 | 可取之处 | 代价或不适用原因 | 本次取舍 |
| --- | --- | --- | --- |
| 功能、缺陷、维护三类 | 入口少，旧表可用 | 独立研究与选择任务混入维护，终点不清 | 保留历史起点，已扩展为五类 |
| 研究与决策合并为四类 | 探索入口集中 | 回答未知问题与作出选择的完成条件不同 | 继续区分 |
| 五类主工作项，交付物独立 | 覆盖不同完成目标 | 需要解释交叉情形 | 保留，不宣称适合所有团队 |
| 只按五类，不说明领域 | 填写少一项 | 无法直接区分团队工作方式与产品本身 | 增加独立领域单选 |
| 把领域与五类组合成十个入口 | 一次选择包含两个维度 | 模板重复、共同修改更易遗漏 | 两个维度分开表达 |
| 按 Prompt、文档、测试、发布继续细分 | 名称直观 | 混合载体、目标和结构层级 | 不新增平行主类 |
| 只靠标签组合 | 自由度高 | 缺少主 Issue 共同入口和主要验收目标 | 保留五类表单 |

## 影响与验证

五份主表、入口名称和填写说明同步领域与类型定义；字段及 Sub-issue 自主表达的取舍集中于共通决定。以五类、跨领域维护和父子关联案例核对分类。#6 的旧入口验证不代表本轮入口已上线；本轮静态、填写和默认分支验证边界见 [本轮验证](../../../../docs/validation/2026-09-10-main-issue-templates.md)。

## 重开条件

实际工作出现领域交叉无法表达、选类持续冲突、研究与决策无法区分时，带实例修订。Sub-issue 的模板化时机按共通决定，不能因其有父项就机械复制主表。
