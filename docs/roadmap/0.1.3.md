# 0.1.3：首次累计源码发布

## 目标

用户获得可检出的固定源码版本，包含工作流执行、三个 Harness 与认证、持久恢复、单机队列、有限重试、单层 JSON Map/固定 Fork，以及已验证的批卷消费端。

## 范围与非目标

首发范围累计包含 #9–#16，对应原 [0.1.1](0.1.1.md)、[0.1.2](0.1.2.md) 和本页重试/并行批次。以 main 926fe2aa59ee05547b8ef2f1f53286ef02aaa4bf 的已验收实现为产品基线；发布准备调整版本元数据、变更记录和文档，并修正 CI 暴露的容量测试短租约；生产源码不变。当前源码版本统一为 0.1.3，所有包保持 private。

不包含未合并的 #40–#42、npm 分发、生产 Tutor 写入、复杂重试平台、嵌套并行、并行文件产物或 Effect；不补造 0.1.1/0.1.2 发布历史。原验收范围与已知限制保持。

## 版本验收

满足 Issue 详细验收；批卷故障注入验证重启后预算不重置；独立 JSON 并行夹具验证顺序、容量和部分恢复。最后使用授权的学生答卷与匹配官方试卷/答案，在新引擎完成批卷、复核、报告及 PDF，记录引擎与评分质量证据。当前 Tutor 串行流程不能替代并行验收。
