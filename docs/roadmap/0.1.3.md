# 0.1.3：累计核心源码交付

## 目标

用户获得可检出的固定源码版本，包含工作流执行、三个 Harness 与认证、持久恢复、单机队列、有限重试、单层 JSON Map/固定 Fork，以及已验证的批卷消费端。

## 范围与非目标

核心范围累计包含 #9–#16，对应原 [0.1.1](0.1.1.md)、[0.1.2](0.1.2.md) 和本页重试/并行批次，沿用最终验收 PR #43 的证据范围，并保留后续已合入修复。根工作区、CLI、DeepSeek 工具、domain、engine、integrations 使用 0.1.3；Studio 使用独立的前端 0.1.4，并依赖这些核心包的实际 0.1.3 版本。所有包保持 private。

#40–#42 已合入的前端和工作台归入 [0.1.4](0.1.4.md)，不混写成核心 0.1.3 的交付条目。不包含 npm 分发、生产 Tutor 写入、复杂重试平台、嵌套并行、并行文件产物或 Effect；不补造 0.1.1/0.1.2 发布历史。当前 main 同时包含前端源码，此处的功能归属不表示 Git tag 可以排除它；原验收范围与已知限制保持。

## 版本验收

满足 Issue 详细验收；批卷故障注入验证重启后预算不重置；独立 JSON 并行夹具验证顺序、容量和部分恢复。最后使用授权的学生答卷与匹配官方试卷/答案，在新引擎完成批卷、复核、报告及 PDF，记录引擎与评分质量证据。当前 Tutor 串行流程不能替代并行验收。
