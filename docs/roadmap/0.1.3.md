# 0.1.3：有限重试与 JSON 并行

## 目标

用户可以配置节点有限重试，并使用单层 Map/固定 Fork 批量处理 JSON。

## 范围与非目标

#15、#16。持久尝试预算、简单等待间隔、JSON Map/Fork、wait-all。不做复杂重试平台、嵌套并行、并行文件产物或 Effect。

## 版本验收

满足 Issue 详细验收；批卷故障注入验证重启后预算不重置；独立 JSON 并行夹具验证顺序、容量和部分恢复。最后使用授权的学生答卷与匹配官方试卷/答案，在新引擎完成批卷、复核、报告及 PDF，记录引擎与评分质量证据。当前 Tutor 串行流程不能替代并行验收。
