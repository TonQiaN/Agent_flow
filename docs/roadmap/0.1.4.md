# 0.1.4：前端与本机工作台

## 目标

成员在本机浏览业务工作流、查看节点和容器配置，通过一次材料上传启动运行，并在同一画布查看执行进度、历史回放及分组产物。

## 范围与非目标

归入 [Issue #39](https://github.com/TonQiaN/Agent_flow/issues/39) 已交付的运行历史与日志、本机 HTTP 服务、招聘工作流、TypeScript/React 画布、上传、回放及文件/PDF 展示，以及合并前后的对应修复。实现已由 PR #40–#42、#47 合入；当前行为与限制见[本机工作台指南](../guides/local-studio.md)。

`@agentflow/studio` 版本为 0.1.4，依赖的 domain、engine、integrations 保持核心 0.1.3；内部精确依赖与锁文件对齐实际包版本。核心交付继续按 [0.1.3 计划](0.1.3.md) 记录，两部分在同一源码树中使用。

不新增公网托管、多租户、复杂业务编辑器、节点 Skills/MCP 配置、npm 分发或发布自动化；不会因为调整版本而扩大既有真实模型、学生样本与招聘验证的结论。
