# 0.1.2：持久恢复与单机任务调度

## 目标

在相同定义和环境下恢复中断流程；多 Run 通过单机 Worker 共同遵守角色与认证容量。

## 范围与非目标

#13、#14。节点边界恢复、持久队列、单机多进程 Worker。暂不做会话接管、历史环境重建、多主机、抢占或复杂公平调度。

## 版本验收

满足 Issue 详细验收；对批卷夹具注入引擎/Worker 中断、取消和多 Run 竞争，验证已完成初批不重跑、旧执行未停不启动副本、容量与结果归属正确。
