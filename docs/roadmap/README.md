# Roadmap

这里展示当前版本安排，不是已实现能力清单。当前项目仍是文档管理骨架，尚无可运行产品或正式发布 tag；当前能力见 [项目文档](../README.md)，实际变化见 [CHANGELOG](../../CHANGELOG.md)。

## 阶段边界与版本总览

以下是待具体规划的阶段方向，不是已承诺的版本验收或发布日期。首发编号、各版范围及升版边界尚未确定；目前没有需要展开的具体版本计划。

| 版本 / 系列 | 核心目标与边界 | 状态 | 计划 / 工作项 |
| --- | --- | --- | --- |
| 0.1.x（候选阶段） | 建立核心工作流能力；具体能力、验收与发布批次待规划 | 计划中 | 待建立对应产品 Issue 与版本计划 |
| 0.2.x（候选阶段） | 在核心能力基础上扩展功能；具体方向待讨论 | 计划中 | 暂无具体版本计划 |

版本管理骨架由 [Issue #4](https://github.com/TonQiaN/Agent_flow/issues/4) 跟进，该工程工作项本身不代表上述产品阶段已经开工或发布。

## 计划文件与相关入口

本目录采用总览加按需版本文件的结构。某个版本开始具体规划时，`<version>.md` 承载目标、范围与非目标、版本整体验收、关联 Issue 和决策；简单补丁可以直接链接完整覆盖其目标与验收的 Issue。远期版本只有总览行，不预建空目录。

总表集中展示版本状态，初期为计划中、进行中、已发布。延期或取消会说明原因和后续去向；详细任务进展仍由 Issue 维护。已发布计划保留在原位置，历史通过 Git 查看。

- [版本维护指南](../development/versioning.md)：创建计划、调整范围、记录变更及发布的实际步骤。
- [版本管理决定](../../.agents/decisions/development/README.md#d-20260908-version-management)：目录、职责和最小发布方式的取舍。
- [产品决策索引](../../.agents/decisions/product/README.md)：产品取舍及其确认边界。
