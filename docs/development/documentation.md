# 文档维护指南

适用阶段：2026-09-07 文档管理骨架。本文记录当前操作；规则的理由分别维护在 [生命周期决定](../../.agents/decisions/development/README.md#d-20260907-decision-lifecycle)、[内容决定](../../.agents/decisions/development/README.md#d-20260907-decision-record-content)及 [分层决定](../../.agents/decisions/development/README.md#d-20260907-documentation-layers)。

决策目录的执行入口是 [.agents/decisions/AGENTS.md](../../.agents/decisions/AGENTS.md)，README 负责说明和导航；两者书写分工见 [唯一负责决定](../../.agents/decisions/development/README.md#d-20260907-agents-writing)。

## 开始一项改动

1. 确认改动影响哪些决策问题，先看相关分类索引、现行决定、alternatives 与独立拒绝项。
2. 按内容决定中的非平凡判据判断。已有记录完整覆盖就引用该 ID；新取舍更新同一问题正文；只有独立新问题才新建。
3. 用 [共同模板](../../.agents/decisions/TEMPLATE.md) 提炼结论、范围、比较、理由与验证方式。研究不充分就标明待讨论，不捏造比较或批准。
4. 新提案进入 proposed；当前任务已有明确采纳指令，可直接登记 accepted，记录实际确认与审阅情况。当前启动期直接设计、直接做，不等待多人审查；目标与取舍见生命周期决定。Issue 是否强制、未来固定审查人数等另议。

## 修改 AGENTS.md

先从文件中的唯一书写决策回链定位负责记录，了解它为何包含当前指令。实质改变职责或规则时，在同一负责决定中补充取舍，再同步 AGENTS.md；新增文件则先确定唯一归属，并在负责决定的完整文件清单中登记。

当前根 AGENTS.md 与决策目录 AGENTS.md 由同一项书写决定管理，CLAUDE.md 复用根文件正文。其他领域决定可提供事实依据，但不因此成为该指令文件的另一项书写决定。对应关系的主清单仅在负责决定中维护。

## 移动与修订

- 事件与目标目录按生命周期决定执行。移动时保留文件名 ID，更新分类 README 中唯一正文路径。
- 正式引用使用分类索引锚点，例如 [D-20260907-decision-lifecycle](../../.agents/decisions/development/README.md#d-20260907-decision-lifecycle)。正文位置改变后，该入口不变。
- 同问题的已确认改选在原正文内更新，旧方案进入 alternatives。未确认的修订写在原文末尾，现行结论继续有效。
- 独立拒绝使用同一模板，写清拒绝范围、原因和重开条件；已有理由用 ID 引用，不复制。
- 同步实际受影响的 docs、实现与验证结果。范围尚未完成时不能标为 implemented；只改错字不转换生命周期。

## 当前说明、验证与复盘

当前操作和能力进入对应 docs 文档，引用决定而不复制其整段论证。验证结果按 [验证记录入口](../validation/README.md) 留存。重大事故按 [复盘入口](../postmortems/README.md) 永久记录，尤其说明已有检查为何没有拦住。

验证和复盘需把必要事实、环境、结论与局限留在正式文档，读者不必访问原始资料才能理解。完整日志等大体积附件可自行保存；它们不能替代正式结论。

## 原始资料的边界

任何开发者都可在 materials 中采用自己的格式和目录组织，已有 artifacts 已整体收容在其中。没有必填材料包字段、统一命名、强制索引或决策回链。进入正式开发的决定仍须按同一模板和流程提炼。

materials/.ignore 让默认 ripgrep 搜索只发现原始区入口 README，不搜索内部正文。它不是访问控制，也不是 Git 忽略规则；其他读取方式同样遵守 AGENTS.md 的语义边界。

日常搜索明确限于正式区域：

```sh
rg -n --hidden '关键词' .agents/decisions docs AGENTS.md
```

任务明确要求研究原始材料时，直接限定到当时可见的目录或文件。原始资料被移动或删除，不需要同步修改正式决定。

## 变更完成前核对

- 同一 ID 只对应一份正文，目录与实际生效/落实情况一致，没有正文 status 字段。
- 替代、拒绝理由有唯一归属，不因文案不同而重复研究同一方案。
- 决策索引、正式链接与模板完整；正式决定不依赖原始资料路径。
- 每份正式 AGENTS.md 具有唯一负责决定，回链与负责决定的文件清单相符；README 未复制一套执行规则。
- 当前说明反映实际行为，未完成事项如实标明；相关验证与重大事故复盘可独立阅读。

这些检查目前按任务执行；尚未接入自动 CI，也尚未建立完整 Issue/PR 工作流。
