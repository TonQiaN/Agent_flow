## 完成边界的反例核对

| 情形 | 核对结论 |
| --- | --- |
| 研究预算用完，但关键问题仍无依据 | 未达到成果标准，不能据此完成验收 |
| 有依据地不采用原设想，问题已得到回答 | 可以按原定结论质量验收，否定答案本身不是失败 |
| 决定已敲定，但同项承诺的模板尚未交付 | 不能用决定替代实现交付 |
| 子项 S1 已完成，S2 或整体要求仍未满足 | 主 Issue 继续保留未完成范围 |
| 主表保留真实兼容要求，但尚不知道具体实现 | 可以表达完整需求，负责人随后确定执行方案 |
