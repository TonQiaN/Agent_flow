# 订阅终端登录验证

## 范围与预检

基线 fb4faa1，Refs #11/#12，复用认证生命周期决定及用户已确认的解耦边界。主责仍为项目负责人，Codex 实施与作者自查；无独立评审和远端 CI 结论。本次不读取真实凭据、不进行 OAuth/模型调用、不自动打开浏览器。

先核对 Blackbox v0.1.22 / 5610d1b 的 cli.py auth 分支、credentials.py 交互 Docker 登录、api_keys.py 终端录入以及对应测试。沿用交互终端与机器状态分开、无 argv 秘密、明确所选服务的处理；Blackbox 无本次终端取消/PTY 超时的对应回归，因此在本项目实际复现验证。其旧文件来源注释不能覆盖用户已明确允许的受控文件导入。

## 实现与验证

CLI auth login codex/claude 显式选择存储、引用、工作区和镜像，组合原生驱动与管理协调器。LoginTerminal 只负责私有终端 IO 和 Cancellation；不处理存储、浏览器或 Docker 生命周期。逐行隐藏输入、局部编辑、有界提交、输出控制字符清理、取消/超时/信号及终端模式恢复分别测试。

编译后的实际 CLI 在 POSIX PTY 中运行，真实 Docker 内的合成登录程序检查授权码字节并写合成凭据。覆盖 Codex/Claude 成功、编辑、Ctrl-C、Ctrl-D、SIGTERM、准备期 SIGTERM、非法/过长/多行输入、超时、持续清理失败。核对输入不回显、原终端模式恢复、stdout 无授权内容、元数据状态以及管理锁可再次取得。清理故障让版本探针正常移除，但拒绝登录容器移除及一次重试：退出 3、pending_cleanup、源未保存、锁和工作区保留。测试结束仅按该合成执行的身份标签清理其资源。

另验证无终端输入在创建状态之前拒绝，重复/秘密/文件/JSON 参数与非法时限拒绝；inspect/delete 两个订阅服务仅检查或删除本地记录，不联网。

## 发现与结果

首轮超时用例出现等待未结束。排查时无残留 AgentFlow 容器，恢复读取 PTY 后 CLI 退出、终端已恢复且显示 AUTH_LOGIN_TIMEOUT。测试脚本原先仅 communicate 读取 stdout，期间不读取私有终端输出；改为同时排空 PTY 和 stdout，避免终端模式恢复期间的输出等待。没有为绕过测试而修改 Runner 停止/清理逻辑。

终端专项修正后 15 项通过。最终 `npm run check` 启用 Docker、egress 与三个固定 Harness 镜像，265 项通过，0 失败、0 跳过，约 106 秒；包括构建、测试类型及依赖边界检查。92 个本地文档链接和 git diff --check 通过。真实 OAuth、原生 Claude 浏览器回调/手动授权码、真实刷新和安全备份恢复未验收。强杀不保证清理；pending_cleanup 仍须原资源对账，跨进程恢复待 #13。此次证据不替代真实订阅或最终学生批卷验收。
