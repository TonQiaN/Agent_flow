当前 CI 配置的七个 job 定义均为标准 `ubuntu-latest`，Node 矩阵展开后有八项检查，没有较大规格 runner。GitHub 官方说明公开仓库的标准托管 runner 分钟免费，较大规格等其他计费项另算；本记录不承诺所有 Actions 服务零费用。[Actions 计费说明](https://docs.github.com/en/billing/concepts/product-billing/github-actions)

GitHub 明确说明 PR refs 为只读，敏感数据的缓存及 PR 引用清理需要联系 Support；旧克隆合并还可能重新引入被移除历史。[清理敏感数据说明](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository)
