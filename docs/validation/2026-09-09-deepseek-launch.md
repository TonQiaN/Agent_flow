# DeepSeek 固定启动与图像交接

关联 #10/#11 和 [Harness 决定](../../.agents/decisions/product/README.md#p-20260909-harness-adapter)。本次完成容器启动资产；宿主 Adapter/Profile/Runner 组合和真实 API 调用仍未交付。

## 参考与实现

先核对 Blackbox Agent Flow 5610d1b / v0.1.22 的 API key 读取/字符验证，以及 1fd414a 图像修复：旧 CLI 本地模型目录缺少图像声明，不能仅凭模型名推断支持。沿用已选 dsh 0.1.1-rc.2 与 deepseek-v4-flash-vision-exp 核对图像路径；随后查原生工具模式与 run_code 规则。

launch.mjs 固定 dsh 安装路径、精确版本、headless profile、只读配置和 /task/work。唯一外部参数是分隔符后的原样任务文本；额外参数不能插入 patch 或程序。启动前从 /task/state/deepseek-api-key.json 读取 schema 为 agentflow-deepseek-key/v1 的内部交接记录，仅包含 schema/api_key；检查属主、仅属主权限、链接、大小、读取期间变化、JSON 和无空白可打印 ASCII 密钥。只将密钥放入 CLI 子进程环境，不放入 argv 或任务配置。启动环境由固定值构造，继承范围仅限 Runner 的受控代理字段。

程序拥有 CLI 进程组，转发取消并在需要时升级终止。非零退出、取消或残留进程不采集成功会话；正常退出且进程组已结束后调用前一切片的原字节采集。程序自身的失败输出为固定诊断；CLI 原始 stdout/stderr 仍作为私有原始日志保留，后续宿主脱敏组合仍有责任。

## 实际验证

仍使用镜像 sha256:a92f35565532db0e3c9ace1454754a0232a35ff413d31ebe3c7a90e7ae78916b / Node 22.23.2；全部断网、合成密钥和合成图片，由容器内本地模型服务驱动真实 CLI。

真实任务现通过固定启动程序运行，父环境放入不同的假密钥，本地服务实际收到的认证与私有文件中的密钥一致，错误认证计数为零。19 次工具调用及最后模型回应的原生日志通过 Runner 采集与严格解析。原有输入副本/输出/共享临时文件、文件/搜索/进程隔离和环境/网络断言继续执行。

增加的图像与入口断言：

- 原生 read_image 读取合成 PNG 后，本地模型请求包含 image_url，解码后的字节与源图片一致。最初使用的测试 PNG 被原生解码器拒绝，修正了测试数据的 PNG 块校验和，再验证实际交接。
- 私有目录中的有效 PNG 和真实交接位置的合成密钥读取均返回工具错误；模型工具结果未出现密钥或父环境中的替代密钥。
- 当前 native 工具目录未显示 run_code，直接调用也返回 unknown tool，测试程序标记未执行；不是仅靠目录缺项作判断。

拒绝路径覆盖缺失/畸形/过大/错误 schema 的密钥记录、含空白的 key、权限过宽、符号链接/硬链接，以及空任务或额外启动参数。全部只输出固定失败标记，不生成原生成功记录。真实 CLI 的合成 HTTP 401 和模型请求期间取消均由启动程序返回失败，Runner 采集的成功记录缺失；不把失败残留会话当作完成证据。

首轮完整回归 187 项通过。随后定点在原始记录 fsync 期间注入 SIGTERM，复现 CLI 已正常退出但采集期间取消仍返回 0 的竞态；核对 Blackbox 相关收尾路径后，在采集结束再次检查取消并删除本次记录。修复后的定点测试返回失败且记录缺失，修复后的完整 npm run check 启用 Docker、受控联网及三个既有 Harness 镜像：188 项通过、0 失败、0 跳过，包含依赖边界、构建、测试类型检查和全部测试。作者验证，无独立评审、远端 CI 或发布。

## 尚未完成

宿主尚未提供对应 API key Profile/Store 与授权网络执行入口，也未完成纯 Adapter 和多出口受控结构化交接。当前成功路径由可信测试服务创建合成私有交接文件并启动程序；它不证明真实凭据管理或完整认证矩阵已完成。本次只验证图像进入模型请求，没有真实视觉理解、OCR、学生批卷或报告/PDF 质量结论。
