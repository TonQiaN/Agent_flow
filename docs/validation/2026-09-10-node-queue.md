## 已验证结果

环境：macOS、本机 Node v26.0.0、TypeScript 5.9.3、Docker CLI 29.4.3。临时 SQLite、子进程、Docker Alpine 脚本及合成数据；不使用真实凭据、官方模型或 Tutor 生产服务。

| 验收面 | 实际证据 | 结果与边界 |
| --- | --- | --- |
| 一次只执行一个节点 | 同一两节点流程执行两次 `runOnce`，第一轮只接纳 A、B 新入队；第二轮结束 Run；严格加载两种状态 | 通过，业务路由仍由正常引擎负责 |
| 重开与重复入队 | 新进程读同一队列/Run，重复 Run ID 创建冲突，取消后不能被领取 | 通过，无重复任务实例 |
| 共享角色和认证容量 | 真实两个子进程同时执行不同 Run；相同身份限 1、角色限 2 时 A/C 执行，B 等待；另一个实验把角色限为 1 | 通过，角色和认证容量分别限制，等待没有 Attempt |
| 启动失败与释放 | 工厂在创建 Attempt 前抛错，任务 blocked、owner 释放，其他任务可领取 | 通过，不自动业务重试 |
| 原子性 | 第二个记录条件冲突时第一个记录无部分写入；只读守卫不增加版本 | 通过 |
| 过期占用和迟到写入 | 旧进程在归属检查后、实际数据库提交前通过 IPC 暂停；期限后新 Worker 接管并完成 A，再恢复旧进程 | 旧提交 `RUN_REVISION_CONFLICT`，已采用 Run 和唯一后继保持不变 |
| 重复提交 | 已完成领取再次通过绑定 Store 写入 | `QUEUE_CLAIM_LOST`，不重复推进 |
| 未确认后继 | A 成功后构造 B 的未确认终态，核对队列不会借用 A 的成功释放 B | 通过，保留占用 |
| 正常停止与取消 | 活跃节点期间 drain/cancel；取消与领取同时竞争 | 通过，不继续领取，不复活已取消任务 |
| 实际 Worker 失联 | A 完成，B 实际容器运行后 SIGKILL Worker，删除原始输入，新进程恢复 | 旧容器清理后 B 新 Attempt，A 不重跑，结果为 seedAB |
| 查询故障恢复 | B 失联后注入不可达 Docker endpoint | blocked 并保留容量，旧容器仍运行，不启动副本；修复后显式恢复并清理旧容器 |

## 认证源联合验收与剩余交付

本轮在基线 5e19635 上接通源预占及实际绑定核对。登录/管理占用同一源时，真实 DeepSeek Worker 返回 CREDENTIAL_SOURCE_BUSY，零 Agent 调用、零新 Attempt、归还调度容量；释放后分别执行 A、B。另一个普通组合证明忙于共享身份的 A 等待时，使用另一身份的 B 可继续。

真实 DeepSeek Worker 在版本探针或执行阶段被 SIGKILL 后均可恢复；旧领取令牌封存，Attempt 2 接纳。Codex、Claude 分别使用实际 Credential Driver、Runner 和合成 CLI：预占连续转给已保存执行资源，失联后源继续保持互斥，共同恢复清理后新 Attempt 成功，刷新源保留，随后 B 成功；没有重新登录或官方模型调用。

普通测试还覆盖未预占旧令牌的迟到获取、活动订阅不能提前释放、管理操作互斥、不可变快照释放后不能读取新密钥、并发忙探测与已预占执行交接、Harness/身份/容量不匹配，以及 Profile 正确但实际源未绑定预占令牌。所有接线错误在新 Attempt 前拒绝。

首次实际 Agent 队列测试因编译器未捕获新增 dispatchBinding 端口而在执行前拒绝；补齐编译器端口捕获后，原三个实际用例通过，未删除或放宽断言。错误诊断改为输出静态错误码，避免将整个执行快照刷入失败日志。

## 2026-09-10 CI 接管测试的租约修正

PR #29 的 39b8494 在 Node 24 push 检查失败：迟到写入测试的新 Worker 返回 QUEUE_CLAIM_LOST，而非预期成功；同头 PR 事件检查通过不抵消这次失败。先检查 Blackbox 5610d1b 的 run_leases.py、test_storage.py 及相关历史：该实现使用 POSIX flock，未提供本项目定时 NodeTask 租约的直接修复。

本测试需要旧 Worker 的 300 毫秒租约到期，以便新 Worker 接管；新 Worker 原来也被设置为 300 毫秒，CI 负载可能使它在恢复期间意外失去领取。修正仅让新 Worker 使用既有默认 30 秒租约，保留旧 Worker 短租约、IPC 暂停位置、接管成功、旧事务 RUN_REVISION_CONFLICT、Run 不变和唯一后继的所有断言。生产实现及默认值未修改。
