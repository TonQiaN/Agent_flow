## 定向验证

4 项通过（约 2.1 秒），其中两项运行真实 Docker：

- 两个实际 Script Catalog 的结构快照相同，但脚本文本或期限不同，执行快照拒绝匹配；编译后替换描述方法不改变原计划来源，修改返回描述不会改变内部事实。
- 缺失或空 backend 描述不能成为持久化证据。
- 并发描述得到同一镜像 ID，尚未创建工作目录。删除仅本测试创建的临时镜像标签后，原 backend 仍成功执行该镜像；新安装使用已删除标签拒绝，使用同一实际 ID 可匹配，修改内存限制拒绝。测试未删除基础镜像，专用标签和容器已清理。
- 分配之后首次冻结、私有状态绑定、交互和联网 backend 均拒绝描述，未调用私有绑定或交互回调。

镜像验证覆盖标签删除后仍使用冻结镜像；没有声称已测试标签被改指到第二个真实镜像。首次测试类型检查发现未导出的无用类型 import 和合成绑定缺少 environment 字段，修正测试声明后通过；不涉及实际执行失败。
