# 联网 Runner 资源恢复验证

## 范围与依据

Issue #13，基线 3068267，沿用[持久化决定](../../.agents/agent_notes/product/README.md#p-20260909-run-persistence)。主负责开发者 @xiaoxuanli-a；Codex 按已有授权实施及作者检查，没有新增独立审阅。当前范围为无私有认证绑定的 CONNECT Script，不将其视为 Agent 认证恢复完成。

先核对 Blackbox v0.1.22 / 5610d1b 的 egress.py acquire/close、runners.py 的代理关联/容器结束与认证收尾，以及提交 5e33d62。参考独立代理/网络清理边界；旧版按 Run/Profile 共享资源并尽力清理，新版沿既有每个 Runner 资源独立的边界，保留严格归属与确认，未复制旧共享锁或 best-effort 成功判定。

## 实现

CONNECT Docker 定义为 agentflow-docker-execution/v2，增加代理程序摘要、固定代理镜像与规范化出口配置。prepareEgress 读取实际构建包的代理程序并固定内容；create 使用相同内容和镜像，不从保存 JSON 构造执行代码。断网仍为 v1，Workflow 检查点仍为 v4。

任务容器、代理、内外网络使用同一唯一资源 ID 派生名称，并标注完整 Run/NodeTask/Attempt/编号。旧资源恢复只建立共同管理句柄，不能 setup/start。只读查询核对归属但允许代理已退出或缺失；停止任务后逐项移除代理及网络，确认全部缺失才可记录完成和释放目录。查询错误不是缺失，同名异属或代理镜像不符拒绝。网络尚有其他成员时移除失败，保留归属目录和可重试句柄，不能删除其他成员。

## 故障注入与结果

新增 11 项真实 Docker/SQLite/新进程资源测试：在 allocated、created、running、exited 暂停并 SIGKILL；工作目录缺失、任务容器缺失、代理缺失仍清理其他资源；代理程序实际挂载字节摘要与保存描述一致；同一资源标签但不同任务身份的代理/网络不清理；Docker 故障和保存的代理摘要变化不能冒充完成；外网残留其他成员时，部分清理不能释放目录，成员由测试自行移除后新进程恢复成功。

原 A/B Workflow 增加 2 项 CONNECT 场景，分别一次及连续两次宿主 SIGKILL，删除原输入及临时文件，恢复只重跑 B 的第 2/3 次 Attempt，A 保留，最终 seedAB；核对旧任务、代理及两张网络全部缺失，并由另一新进程严格加载归档结果，存储 revision 不变。

首轮 14 项检查中 13 通过、1 失败：执行定义测试直接导入 TypeScript 源模块，代理资产路径落在尚无 proxy.js 的源码目录。回查 Blackbox 的实际代理源文件加载边界后，将该 E2E 改用构建后的公开包，与生产部署入口一致；没有在运行时猜测源码路径或临时编译。随后补入部分清理重试和联网 Workflow 场景再回归。第二轮 68 项中 66 通过、2 项 CONNECT Workflow 失败，定位到文件收据恢复硬编码只接受 Docker v1。先核对 Blackbox runtime.py 的收据链身份/前序摘要检查，再让内部一次性加载请求识别已由实际定义比较验证的 v1/v2；保留镜像、身份、前序输入与文件清单的逐项核对，并增加 CONNECT 收据镜像被改写时必须在认领和清理前拒绝的断言。

## 最终验证

最终普通测试 285 项全部通过（8.04 秒）；相关真实集成测试 68 项全部通过（133.20 秒），共 353 项，无失败、取消或跳过。集成范围包括联网资源恢复、Runner 资源、执行定义、Workflow 检查点与恢复、出口代理，以及三种 Agent 的合成组合和执行定义；不是当前全套原生 Harness / 登录矩阵的重跑。

构建、测试类型检查、生产依赖边界、604 个本地文档链接及 git diff --check 通过。本地作者检查使用 Node 26，不替代 Node 24 CI 或独立审阅。

## 剩余边界

prepare/create/start 的 pending 操作仍保守拒绝自动接管，不从宿主 PID、时间或一次 absent 推断旧外部命令结束。私有认证和交互绑定仍不可持久恢复；Agent 版本探针资源、认证占用恢复、文件收据与其他函数/Effect 路径尚有缺口。本轮仅使用本地合成脚本和代理健康检查；相关代理回归按原测试范围验证出口，没有读取真实账号或调用真实模型、学生批卷。没有机器断电或独立评审证据，#13 保持未整体验收。
