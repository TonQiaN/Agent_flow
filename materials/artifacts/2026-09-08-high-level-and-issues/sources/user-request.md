# 本轮用户要求

来源：2026-09-08 当前 Codex 对话中的用户消息。以下正文原样保留。

请从飞书COE组织里我和小轩的对话里获取现在讨论的关于这个项目的版本和项目功能的描述讨论当作参考。

1. 此项目现在初步敲定一下项目的high level的功能，根据讨论的内容，我发现和前端展示有关的没有涉及到。前端第一版定为只是展示，展示工作流编排的结果，对应的prompt，对应的container环境。运行之后的历史，要能有时间性的轨迹回放。包含其他我没想到的前端展示，也对应到issue划分里。
2. 对于issue的划分我有建议，除了功能模块化划分以外，请再加上一些比如敲定high level 功能的issue，这种issue的验收可以就是一些decisions。所有的issue请整理到artifacts，并把额外的issue明确标出来。
3. 请从之前两小时的逐字稿里参考有什么值得改进的地方，一并整理。
4. 版本号管理本身就是开发流程的决策，属于不平凡开发，需要issue，审查相关的需要流程改动的改变并总结issue。
5. 我认为container的能力，环境管理是项目核心内容之一，需要更多的讨论，验证，细化需求，前端展示等。
6. issue的提交，除了要求对应功能，修复bug等，还可以加上研究功能或者讨论实现等这种和功能相关的，产物就光是决策文件的issue。所以issue的模版应当尽早敲定，并不断完善（这本身也是一个issue）。

请将以上要求做成一个artifacts到materials里，暂时不要启动建立issue的流程，当前仅讨论。
